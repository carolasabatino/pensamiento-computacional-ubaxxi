# Pensamiento Computacional — UBA XXI

Repositorio con las prácticas y ejercicios realizados para la materia **Pensamiento Computacional** de **UBA XXI**.

## 📚 Contenido

En este repositorio se encuentran las actividades prácticas desarrolladas durante la cursada, utilizando **Python** y **Google Colab**.

### Temas trabajados

#### Introducción a la algoritmia y a la programación
Metodología de resolución de problemas. Concepto de algoritmo. Concepto de Programa.
Concepto de lenguaje de programación. El lenguaje de programación Python. Sintaxis y
gramática de Python. El intérprete de Python. Variables: concepto y ejemplos.
#### Tipos de datos, expresiones y funciones
Tipos de datos simples. Números: entero, real. Cadenas. Booleano. Funciones: Concepto.
Comentarios. Operadores: Operadores Lógicos, Relacionales. Expresiones. Concepto de
Expresión. Expresiones booleanas. Funciones. Parámetros. Tipo y valor de retorno.
#### Estructuras de control
Estructuras de control: Concepto. Estructuras condicionales: if, else, elif. Estructuras de
control iterativas: while, for, range.
#### Tipos de datos estructurados
Tipos de datos estructurados. Secuencias: tuplas y listas. Listas. Operaciones con listas.
Mutabilidad. Diccionarios.
#### Entrada y salida de información
Manejo de archivos. Manejo de errores.
#### Bibliotecas
Concepto. Uso de bibliotecas. Import. Introducción al análisis exploratorio de
datos con Pandas. Visualizaciones básicas con Matplotlib.
