# Pensamiento Computacional — UBA XXI

Repositorio con las prácticas y ejercicios realizados para la materia **Pensamiento Computacional** de **UBA XXI**.

## 📚 Contenido

En este repositorio se encuentran las actividades prácticas desarrolladas durante la cursada, utilizando **Python** y **Google Colab**.

### 1. Introducción a la algoritmia y a la programación

Metodología de resolución de problemas. Concepto de algoritmo. Concepto de Programa. Concepto de lenguaje de programación. El lenguaje de programación Python. Sintaxis y gramática de Python. El intérprete de Python. Variables: concepto y ejemplos.

**Prácticas:** [Práctica 1](Practica_01.ipynb)

### 2. Tipos de datos, expresiones y funciones

Tipos de datos simples. Números: entero, real. Cadenas. Booleano. Funciones: Concepto. Comentarios. Operadores: Operadores Lógicos, Relacionales. Expresiones. Concepto de Expresión. Expresiones booleanas. Funciones. Parámetros. Tipo y valor de retorno.

**Prácticas:** [Práctica 2](Practica_02.ipynb)

### 3. Estructuras de control

Estructuras de control: Concepto. Estructuras condicionales: if, else, elif. Estructuras de control iterativas: while, for, range.

**Prácticas:** [Práctica 3](Practica_03.ipynb)

### 4. Tipos de datos estructurados

Tipos de datos estructurados. Secuencias: tuplas y listas. Listas. Operaciones con listas. Mutabilidad. Diccionarios.

**Prácticas:** Próximamente.

### 5. Entrada y salida de información

Manejo de archivos. Manejo de errores.

**Prácticas:** Próximamente.

### 6. Bibliotecas

Concepto. Uso de bibliotecas. Import. Introducción al análisis exploratorio de datos con Pandas. Visualizaciones básicas con Matplotlib.

**Prácticas:** Próximamente.
